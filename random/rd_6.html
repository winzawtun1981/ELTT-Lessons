ရောက်တတ်ရာရာ အင်္ဂလိပ်စာ (၆)


သင်ဟာ ဒီစာကိုဖတ်နေတယ်ဆို သင့်မှာ စမတ်ဖုန်း (smartphone) တစ်လုံး ရှိနေလို့ပေါ့။ အခုခေတ်မှာ စမတ်ဖုန်းမသုံးတဲ့သူ မရှိသလောက်ပါပဲ။ စမတ်ဖုန်းများဟာ သေးငယ်ပေမယ့် လုပ်ဆောင်ချက်များစွာ လုပ်နိုင်ပါတယ်။ ဒါကိုတော့ (versatile) ဆိုတဲ့ နာမဝိသေသနလေးကိုသုံးပြီး ပြောလို့ရပါတယ်။ စမတ်ဖုန်းများဟာ ဖုန်းခေါ်ဆိုခြင်း၊ e-mail များ စစ်ဆေးကြည့်ရှုခြင်းနှင့် ဂိမ်းကစားခြင်းတို့အပါအဝင် လုပ်ဆာင်ချက်များစွာကို လုပ်ဆောင်နိုင်ပါတယ်။ အဲဒါကို ဒီလိုရေးလို့ရပါတယ်။

Smartphones are versatile devices that can be used for a variety of tasks, including making phone calls, checking emails, and playing games.

ဒီလောက်သေးငယ်တဲ့ ကိရိယာလေးတစ်ခုဟာ ဒီလိုများပြားလှတဲ့ လုပ်ဆောင်ချက်တွေကို ဘာလို့လုပ်နိုင်တာလဲလို့ သင် စဉ်းစားမိဖူးလား။ စမတ်ဖုန်းတစ်လုံးကို အစိတ်အပိုင်းများစွာနဲ့ ပေါင်းစပ်ဖွဲ့စည်းထားပါတယ်။ အဲဒီထဲမှာမှ သူ့ရဲ့ ဦးနှောက်လို့ပြောလို့ရတာကတော့ CPU ပဲဖြစ်ပါတယ်။ central processing unit ကို အတိုကောက်သုံးထားတာဖြစ်ပါတယ်။ မြန်မာလိုလည်း အတိုကောက် စီပီယူ လို့ပဲ ခေါ်ကြပါတယ်။

စီပီယူကို ရှပ်ထွေးတဲ့အစိတ်အပိုင်းတွေနဲ့ ဖွဲ့စည်းထားပါတယ်။ စီပီယူထဲမှာပါဝင်တဲ့ အခြေခံအကျဆုံးအစိတ်အပိုင်းကတော့ လျှပ်စီးကြောင်း (electric current) ကို ထိန်းချုပ်ပေးတဲ့ပစ္စည်းပဲ ဖြစ်ပါတယ်။ ၎င်းကို transistor လို့ ခေါ်ပါတယ်။ စီပီယူတစ်ခုမှာ transistor သန်းပေါင်းထောင်ချီပြီး ပါဝင်ပါတယ်။

သင်ဟာ ဖုန်း ရီဗျူးလုပ်ပေးတဲ့ Youtube video တွေ ကြည့်ဖူးတယ်ဆိုရင် ဒီစမတ်ဖုန်းကတော့ ဘာစီပီယူကိုသုံးထားတယ် ပြီးတော့ ဒီစီပီယူက 10nm, 8nm, 7nm ဖြစ်တယ်လို့ပြောတာ သတိထားမိကြပါလိမ့်မယ်။ nm ဆိုတာ nanometer ကို အတိုကောက် သုံးထားတာဖြစ်ပါတယ်။

nanometer ဆိုတာ တစ်မီတာကို သန်းပေါင်းတစ်ထောင်ပုံ ပုံလိုက်ရင် ရလာမယ့် အရွယ်အစားပဲဖြစ်ပါတယ်။ ဥပမာ 7nm ဆိုရင် တစ်မီတာကို သန်းပေါင်းတစ်ထောင်ပုံ ပုံလိုက်ရင် 7 ပုံအရွယ်အစားရှိပါတယ်။

ဖုန်း ရီဗျူးလုပ်တဲ့သူတွေပြောတဲ့ 10nm, 8nm, 7nm ဆိုတာတွေဟာ စီပီယူထဲမှာပါဝင်တဲ့ transistor ရဲ့ အရွယ်အစားတွေဖြစ်ပါတယ်။ အကြမ်းဖျဉ်းအားဖြင့် ပြောရမယ်ဆို စီပီယူတစ်ခုဟာ ပါဝင်တဲ့ transistor အရွယ်အစားသေးရင် စွမ်းဆောင်ရည် (performance) ပိုကောင်းပြီး စွမ်းအင်သုံးစွဲမှု သက်သာပါတယ်။ power-efficient ဆိုတဲ့ စကားလုံးလေးကို အသုံးပြုပြီး ပြောလို့ရပါတယ်။

စီပီယူတစ်ခုမှာ transistor သန်းပေါင်းထောင်ချီပြီးပါဝင်တယ်ဆိုတာ သင် သိသွားပါပြီ။ အဲဒီ transistor များဟာ ခလုတ် (switch) အသေးစားလေးတွေ ဖြစ်ကြပါတယ်။ သူတို့ဟာ ပွင့်နေတာလား (on state) ဒါမှမဟုတ် ပိတ်နေတာလား (off state) ဆိုတဲ့ အခြေအနေတစ်ခုကို ပြနေပါတယ်။ လျှပ်စီးကြောင်းကို စီးဆင်းခွင့်ပြုရင် ON ဖြစ်ပြီး လျှပ်စီးကြောင်းကို စီးဆင်းခွင့်မပြုရင် OFF ဖြစ်ပါတယ်။

transistor များဟာ တစ်စက္ကန့်မှာ အကြိမ် သန်းပေါင်းများစွာ အဖွင့်အပိတ် ပြုလုပ်နိုင်ကြပါတယ်။ on state ကို "1" လို့ သတ်မှတ်ပြီး off state ကိုတော့ "0" လို့ သတ်မှတ်ပါတယ်။ အဲဒါကို binary code လို့ ခေါ်ပါတယ်။ ဒါဟာ စီပီယူက နားလည်တဲ့ ဘာသာစကားပဲဖြစ်ပါတယ်။

ဒီလောက်စွယ်စုံရနေတဲ့ စမတ်ဖုန်းတစ်လုံးရဲ့ စီပီယူဟာ "1" နဲ့ "0" ကိုပဲ နားလည်နိုင်တယ်ဆိုတာ သင့်အတွက် ယုံနိုင်စရာမကောင်းဘူးမဟုတ်လား။ စာရေးသူလည်း ပထမဆုံးလေ့လာသိရှိခဲ့တုန်းကလည်း သင်တို့လိုပဲ တအံ့တဩဖြစ်ခဲ့ရပါတယ်။ သင်ဟာ စမတ်ဖုန်းနဲ့ ဓာတ်ပုံတစ်ပုံရိုက်လိုက်တယ်၊ ဒါမှမဟုတ် Facebook မှာ post တစ်ခုတင်တယ် ဒါမှမဟုတ် အခြားသူတစ်ယောက်ရဲ့ post ကို react ပေးလိုက်တယ်ဆိုတာဟာ သင့်စမတ်ဖုန်းရဲ့ စီပီယူကို ညွှန်ကြားချက် ( instruction ) ပေးလိုက်တာပါပဲ။ အဲဒီညွှန်ကြားချက်တွေဟာ ကြားမှာ အဆင့်ဆင့်ပြောင်းလဲရင်း နောက်ဆုံး စီပီယူက နားလည်တဲ့ binary code အဖြစ် ပြောင်းလဲသွားပါတယ်။

အခု သင်ဖတ်နေတဲ့စာတွေဟာ စီပီယူအတွက်တော့ "1" နဲ့ 0 အတန်းလိုက်ကြီးဖြစ်နေမယ်လို့ သင် စဉ်းစားမိသွားမယ်ထင်ပါတယ်။ မသိလိုက်ရသေးတာတွေကို သိလိုက်ရလို့ သင် ကျေနပ်ပျော်ရွှင်မယ်လို့ စာရေးသူ မျှော်လင့်ပါတယ်။ ဒီသင်ခန်းစာလေးကို ဒီလောက်နဲ့ပဲ ရပ်နားခွင့်ပြုပါ။

Glossary

  • smartphone - a mobile phone that also has some of the functions of a computer, for example the facility to use apps and the internet
  • versatile - able to do many different things
  • CPU - central processing unit (that part of a computer that controls all the other parts of the system)
  • electric current - the flow of electricity in an electronic circuit
  • transistor - a small electronic device used in computers, radios, televisions, etc. for controlling an electric current as it passes along a circuit
  • nanometer - one thousand millionth of a meter
  • performance - the amount of useful work accomplished (by a computer system)
  • power-efficient - conserving energy or operating at a lower energy level
  • binary code - a coding system using the binary digits 0 and 1 to represent a letter, digit, or other character in a computer or other electronic device
  • instruction - a piece of information that tells a computer to perform a particular operation
